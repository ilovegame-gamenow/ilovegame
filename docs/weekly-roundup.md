# 今週発売のゲーム

トップの固定サイズカードから `/weekly-roundup.html` へ進む。月間カレンダーは `/calendar.html` として独立し、両ページから相互に移動できる。

トップカードは、実データの作品名を最大2本入れた「『作品A』や『作品B』などが登場！今週発売のゲームまとめ【○月○日～○日】」という見出しと画像の帯で紹介する。3作品以上の場合だけ「など」を添える。機種違いで作品名・画像を重複させず、画像は最大6作品（小画面では4作品まで表示）。0作品でも多数でもカードの高さは固定し、各作品の日付・機種をトップで1行ずつ並べない。週まとめページの見出しも同じ共通関数で組み立てる。

代表作と画像の順序は `weekly-featured-policy.js` に分離した編集方針で選ぶ。著名シリーズを優先し、次に関連記事の注目度、発売日、タイトルを使う。知名度の実測ランキングではなく、既知シリーズの編集用リストであり、シリーズ認識の対象は必要に応じて見直す。記事の公開点数と作品の知名度を同一視せず、未知の作品の紹介も維持する。詳細ページの本文・目次と月間カレンダーの発売日順は変えない。

週まとめとトップカードは `GET /api/news?resource=calendar&view=roundup&region=JP` を共用する。JSTの月曜日〜日曜日を対象に、既存の確認済み発売情報を発売日順で表示する。機種・地域・正式発売／早期アクセスの区別、延期・中止の除外は月間カレンダーと共通。同日・同作品・同区分の複数機種は既存の集約を使い、日付が異なる機種は分ける。

紹介文・画像・動画は `article_games` で紐づけた記事のうち、`published_articles` に実際に表示される最新の記事から取得する。非公開・審査待ち記事・下書きは利用しない。記事の要約と「ここに注目♪」、検証済み形式の公式動画、詳細記事へのリンクを表示する。発売日は記事の文章から抽出せず、確認済み発売情報を正本にする。

紹介データがない場合も発売情報と公式出典を表示する。紹介取得失敗では発売情報だけを返し、`detailsUnavailable` と再試行の入口を示す。発売情報そのものの取得失敗ではエラーと再試行を表示する。画像取得失敗は画像を隠し、動画は共有プレイヤーを最初から表示し、YouTubeへの直接リンクを残す。

週まとめは登録済みデータをその時点で表示するページであり、新しい記事レコードの自動生成や保存済み本文の書き換えは行わない。公式情報の再調査・発売日訂正は既存の保守運用を使う。
