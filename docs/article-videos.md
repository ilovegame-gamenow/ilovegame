# 記事の公式動画

公開記事・編集室のプレビュー・週まとめは official-video.js と article.css のプレイヤーを共用する。プレイヤーは初めから表示し、画面外の iframe は loading=lazy とする。自動再生はしない。埋め込みが制限されている場合に備え、YouTubeへの直接リンクも常設する。

通常記事は、確認済みの公式動画を本文の独立した行に `公式動画：https://www.youtube.com/watch?v=動画ID` と記載する。その位置にプレイヤーを表示し、異なる複数の動画に対応する。本数の固定上限は設けず、同じ動画IDは最初の位置だけ表示する。情報元そのものがYouTube URLの場合も対応する。通常の文章に含まれるリンクから勝手に動画を推測しない。保存済み記事の変更、スキーマ変更、動画の自動探索はこの変更では行わない。

IDとホストは共通パーサーで検証し、埋め込みURLは固定のyoutube-nocookie.comから組み立てる。HTMLや任意のiframe URLは受け付けない。公開記事と下書きの分離は既存の本文保存・表示経路に従う。
