# 作品管理のタイトル検索

2026年11月6日。作品管理の「ゲームを探す」で、登録済み作品、Steam、日本のApp Store、Wikidataの全機種のゲーム作品データを並列検索する。追加の有料生成API・検索API、APIキー、DB構造の変更は使用しない。

## 表示と確認範囲

作品名、紹介・説明、取得できた対応機種、検索元、出典リンクを表示する。Steamの画像は実際の検索応答に含まれるHTTPS画像だけを使う。WikidataのP31がvideo gameである作品を採用し、漫画やシリーズ項目を除外する。日本語・英語・多言語共通ラベルを扱う。Wikidataの情報は参考情報であり、P856のリンクは参考の公式サイトリンクとして表示する。日本発売や最新の対応機種、発売日を確認済みの事実として保存・公開しない。App Storeは日本ストアのゲームカテゴリのみを対象とする。

全機種の公式ストアを直接横断する検索ではない。Wikidataに未登録の新作やインディー、表記違いなどは検索できない場合がある。「見つからない作品を探す・登録する」にWeb検索とタイトル指定の追跡登録を残す。検索元ごとの件数と失敗を分けて表示する。検索対象の全件取得や網羅を保証しない。

## 登録

「★ このゲームを追う」で既存のcreate_followed_gameを使用する。外部IDだけを受け取り、サーバーで実際の検索元へ再照会して作品名・説明・出典を決める。任意のURL・説明・公開状態をクライアントから受け付けない。Wikidataはmedia、日本のApp Storeはstoreとして保存する。新規作品は下書きであり、お気に入り登録と公開・発売日カレンダー登録は別。

登録済みの同一出典を照合し、一意に一致した作品は再登録せずお気に入りをONにする。WikidataにSteam IDがある場合はそのURLも照合する。タイトルの一致だけで同名別作品を統合しない。同一出典の重複登録は既存のDB関数のロックでも防止する。異なる出典しかない同名作品の自動統合は行わない。

## 通信

公開先は固定したSteam、Wikidata、AppleのAPIのみ。Wikidataは利用者を示すUser-Agentを送る。応答サイズ・タイムアウトを制限し、成功した検索をプロセス内で5分、最大64件キャッシュする。外部の文章はプレーンテキストで描画し、リンクはHTTPSのみ。公開API・記事本文へ編集室の検索結果を追加しない。

## 検証

テストでゲーム以外の除外、対応機種ラベル、部分失敗、登録時の再照会、既存出典の再利用、不正入力、表示・登録操作を確認する。本番記事・作品を検証目的で追加・変更しない。
