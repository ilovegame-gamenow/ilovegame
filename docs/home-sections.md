# 公開トップの役割

- 最新ニュース：全公開記事をサイト掲載日時の新しい順に表示。
- 注目のゲーム：作品に出会うための枠。具体的な遊びの特徴、独創性、発見価値で選ぶ。最大表示件数は既存pickup_max_articles。14日以内の期限付き。
- 速報：重要で新しい発表がある時だけ上部に1件。選定から最長24時間（設定が短い場合は設定を優先）。
- 発売カレンダー／今週発売のまとめ：従来の確認済み発売情報を使用。

選定はprivateなarticle_feature_slotsが正本。reasonは外部へ返さず、公開APIはpublished_articlesから取得できる記事だけを返す。失効・非公開記事は除外し、速報との重複を抑える。記事のimportanceやis_breakingは公開判定・互換性のため保持するが、この枠の自動選定には使用しない。

breaking_threshold/pickup_thresholdの保存値は既存設定API互換のため保持する。画面の旧スコア入力は非表示。今後のデータ整理時に全参照を確認してから廃止する。

処理役は今回公開成功した記事を独立基準で選ぶ。既存の有効な同作品の注目枠を追加しない。再実行で期限を延長しない。記事点数・公開本文・記事状態は枠選定で変更しない。
