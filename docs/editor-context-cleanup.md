# 記事の作品・発見理由と画面整理

記事プレビューは `editor-article-context.js` と認証済み `/api/editor-games?resource=context` を使う。
記事内容の取得・下書き保存から独立し、理由の取得失敗でも記事の編集・公開操作は続けられる。

- 記事下に作品名、作品管理へのリンク、お気に入りの切替、作品登録・変更を表示。
- 発見経路・見つけたきっかけ・注目した理由は `article_discovery_context` に記録。
- 記録がなければ「未記録」。過去の発見理由を推測生成しない。
- 作品管理の理由欄は、関連記事の記録（最近20件）と採用済みの発見理由（最近10件）を読む。
- 発見理由の記録は編集室専用。公開記事API・公開本文には追加しない。
- AI処理役は今回処理した記事の評価理由と作品の関連を保存。収集役は新規候補の発見経路・きっかけを保存。
- 収集役は変更時点で停止中。有効化・スケジュール変更はしていない。新手順の定期実行は別途確認が必要。

## 整理したファイル

`editor-discoveries.html`（転送専用）と旧有料AI探索画面 `editor-research.html` / `editor-research.js` を削除。
旧URLは `vercel.json` の一時転送で `/editor-games.html#find` に集約。
情報元一覧の入口と、メディア・紹介作品画面からの戻り先を更新。

## 残したもの

`editor-showcase` / `editor-media` / `editor-social` は既存APIや設定から参照される別用途の確認画面。
`editor-discoveries.css` は紹介作品画面から参照中。
`lib/game-research*` と既存発見APIは資料プレビュー・テスト等から参照されるため今回削除していない。
既存DBの候補・作品・公開記事・発売日・確認履歴は削除していない。
