# 作品管理の操作整理

記事や資料を作品単位でまとめる役割を短く示し、主操作を「作品名で探す」に絞る。作品ID・紹介・資料は各作品の詳細にまとめ、初期表示を簡潔にする。新規登録は必要な時に開き、作品名と出典を中心に、原題・紹介文・出典の種類は任意の詳細へまとめる。

記事から開いた時は出典URLを引き継ぐ（Nintendo/PlayStationは公式、その他の媒体はmedia。編集者が変更可能）。記事タイトルから作品名を推測して自動登録しない。見つからなかった検索語は、新規登録を開いた時に作品名へ引き継ぐ。既存作品は「この作品を使う」で関連づけ、新規作品は「登録してこの記事に使う」で登録から関連づけまで続けて実行する。記事なしの作品管理では登録のみ。

既存のcreate/link API、入力検証、認証、DB制約を利用し、新APIやスキーマは追加しない。二つの操作は単一トランザクションではないため、関連づけに失敗した場合は登録済みであることを知らせ、同じ作成ID・入力で再試行できるよう残す。作成・関連づけは既存の重複防止により安全に再送できる。失敗時に作品を削除しない。

入力途中の保存は記事IDごとに分ける。他の記事で入力中の作品が意図せず混ざらないようにし、出典の初期入力だけでは離脱警告を出さない。既存の入力途中の復元と期限切れ退避を維持する。

作品の公開・記事公開・自動AI処理は追加しない。発売日編集、作品名の自動抽出、作品の基本情報を後から編集する機能はこの変更には含めない。
